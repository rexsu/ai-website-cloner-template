# Bohrium Science Space - Page Brief
URL: https://www.bohrium.com/en/bohrscience
Date: November 12, 2026
Desktop Resolution: 1440x900

## Executive Summary
A Chinese-language SaaS landing page for "Bohrium Science Space" (玻尔科学空间 Beta), an AI-powered scientific research platform. Despite the `/en/` URL path, the content is entirely in Simplified Chinese. The design is modern, clean, and minimalist with generous whitespace, following current SaaS UI trends.

## Design System

### Color Palette
**Primary Colors:**
- Background: `#FFFFFF` (White)
- Primary Text: `#1F2329` (Near black)
- Secondary Text: `#4E5969` (Dark gray)
- Tertiary Text: `#86909C` (Medium gray)

**Accent Colors:**
- Brand Primary (Purple): `#7B42F6` / `#8A5CF5` (vibrant purple)
- Brand Hover: `#6B46FF`
- Lavender Background: `#F3F0FF` / `#EBE8FF`
- Light Blue: Used in background gradients

**Interactive States:**
- Button Primary: `#165DFF` (Vibrant blue)
- Button Hover: `#4080FF`
- Button Active: `#0E42D2`

**Status Colors:**
- Success: `#00B42A` (Green)
- Warning: `#FF7D00` (Orange)
- Error: `#F53F3F` (Red)

**Borders:**
- Primary: `#E5E6EB` (Light gray)
- Secondary: `#C9CDD4` (Medium-light gray)

### Typography
**Font Family:**
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

**Monospace:**
```css
font-family: ui-monospace, SFMono-Regular, "SF Mono", Consolas, "Liberation Mono", Menlo, monospace;
```

**Hierarchy:**
- H1: Large, bold, black (~40-48px)
- H2: Medium-large, bold (~28-32px)
- Body: Regular weight (~14-16px, color: #4E5969)
- Small/Caption: ~12-13px

**Line Heights:**
- Normal: 1.5
- Loose: 1.75

### Spacing System
```
--ds-spacing-xs: 4px
--ds-spacing-sm: 8px
--ds-spacing-md: 12px
--ds-spacing-lg: 16px
--ds-spacing-xl: 24px
--ds-spacing-xxl: 32px
```

### Border Radius
```
--ds-border-radius-sm: 2px
--ds-border-radius-md: 4px
--ds-border-radius-lg: 8px
--ds-border-radius-xl: 12px
--ds-border-radius-full: 999px (pills)
```

### Component Styles
**Buttons:**
- Primary: Black bg (#1A1A1A), white text, rounded corners (8-12px), padding (~16px 32px)
- Secondary/Ghost: White bg, black border (1-2px), black text
- Border radius: ~8-12px

**Cards:**
- White background
- Rounded corners: 12-16px
- Subtle drop shadow: `0 2px 8px rgba(0,0,0,0.08)`
- Generous padding: 24-32px

**Badges/Pills:**
- Light purple/lavender background
- Dark purple text
- Border radius: 999px (fully rounded)
- Padding: 4px 12px
