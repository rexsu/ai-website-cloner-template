# 七仔首页与戒指页简报

观察日期：2026-11-02。桌面证据来自约 1280×800 的源站截图，见 `docs/design-references/oura/`。移动端源站菜单未完整截到，本地按同一信息架构做了汉堡菜单，并在本地移动视口复核。

## 首页顺序

1. 豆沙绿提示条 + 粘性导航（左标志、中部菜单、右购物袋）
2. 全幅主视觉。桌面图左文右图；移动图手在上方、文在下方
3. 居中衬线标题 + 两枚深色胶囊按钮
4. 横向主题卡，左上标签、右上「+」、底部标题、两端箭头
5. 大号衬线陈述 + 三台手机叠放
6. 三列场景卡
7. 左文右暗色面板的「身心观察」
8. 近黑手记区：左大图、右三则
9. 深色页脚：邮箱、四列链接

## 测量（源站取样）

- 页面底：`#f7f1e8`（主视觉左缘 `#f4e7dc`）
- 顶条：`#ced4b8`
- 主按钮：`#2a72de`
- 深色区块：`#1c1b1a`；页脚：`#363433`
- 戒指主视觉灰：约 `#5c5e66`
- 标题：细衬线，很大，行高接近 1
- 按钮：全圆角胶囊

## 交互

- 主题卡「+」打开说明层，Esc 关闭
- 卡片区横向滚动，箭头每次约一张
- 导航在桌面展开子项，在窄屏改为全屏菜单
- 购物袋是空状态，不进入支付
- 戒指页颜色切换主图；「看结构说明」说明短片未制作，不播放空白视频
- 七仔同行问答为手风琴

## 刻意改写

Oura 的 86% 会员、99% 心率、95% 睡眠分期、$399 起、HSA/FSA，都不写进七仔。应用拼贴和会员头像带有 Oura 界面或真人肖像，已下载但未上屏，避免把别人的界面和脸安到七仔上。手机用本地绘制的界面代替。
